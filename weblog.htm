Web structure:
===========
Entry point -> index.html :
[Tennis Court]
tc.htm(top court) + bc.htm(bottom court) +
LEFT side : lce.htm(left court end) + lct.htm(left court top) + lcb.htm(left court bottom)
RIGHT side : rce.htm(right court end) + rct.htm(right court top) + rcb.htm(right court bottom)
[Main]
main.htm
=================================
PS. add Target=main for each URL tag
__. add Target=_Top for each URL tag: to prevent GO HOME looping in frame.
